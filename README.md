# Global Population Analytics Dashboard

A data visualization project that analyzes global population distribution using World Bank demographic data. The project leverages Python-based analytics and visualization techniques to uncover population trends across countries and income groups.

---

## Problem Statement

Understanding population distribution is essential for governments, policymakers, researchers, and organizations to make informed decisions regarding economic planning, resource allocation, infrastructure development, and social welfare programs.

This project analyzes global population data obtained from the World Bank and visualizes population distribution across different countries and income groups using Python-based data visualization techniques.

---

## Overview

Global Population Analytics Dashboard explores worldwide population trends and presents insights through visual analytics.

The project focuses on:

* Population distribution across countries
* Comparison of population among income groups
* Identification of highly populated regions
* Data-driven demographic insights through visualization

The dataset is sourced from the World Bank's open data platform and processed using Python libraries for data analysis and visualization.

---

## How to Run

### 1. Download the Dataset

Download the latest population dataset from the World Bank:

https://data.worldbank.org/indicator/SP.POP.TOTL

### 2. Set Up Your Workspace

Place the downloaded dataset in the same directory as `script.py` and rename it as:

```text
Task-01.csv
```

### 3. Install Dependencies

```bash
pip install pandas matplotlib numpy
```

### 4. Execute the Script

```bash
python script.py
```
